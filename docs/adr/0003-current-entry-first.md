# Keep the current entry first

Keep the current playback entry at the head of the persistent queue, and allow drag reordering only among upcoming entries. Selecting an existing later occurrence moves it to the front without duplicating it or discarding unfinished entries; selecting a new video prepends it while retaining the interrupted head and its progress immediately afterward. This deliberately replaces an arbitrary playback cursor and wraparound ordering with one visible playback order shared by the player and special playlist.
